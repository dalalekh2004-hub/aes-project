# AES Implementation 🔐

This project implements the AES-128 encryption and decryption algorithm using Python.

## 📌 Features
- AES Encryption (10 rounds)
- Key Expansion
- SubBytes, ShiftRows, MixColumns
- Full Decryption (Inverse Cipher)

## ▶️ How to Run
1. Install Python
2. Run:
   python aes.py

## 📊 Example
Input: 00112233445566778899aabbccddeeff  
Output: 69c4e0d86a7b0430d8cdb78070b4c55a
